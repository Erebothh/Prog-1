# Guías del proyecto

Estas guías complementan los README de cada práctico. La idea es que sirvan para estudiar, preparar la exposición y subir los aportes a GitHub.

| Archivo | Para qué sirve |
| --- | --- |
| [`GUIA-JAVA.md`](GUIA-JAVA.md) | Java desde cero: tipos, operadores, estructuras de control, métodos, clases, herencia, interfaces, excepciones, colecciones, `enum`, palabras reservadas y errores comunes. |
| [`RECORRIDO-DEL-CODIGO.md`](RECORRIDO-DEL-CODIGO.md) | Qué hace cada clase del proyecto y por qué está escrita así. Incluye TP0, TP0-extras, TP1, Entregable 1 y Entregable 2. |
| [`GUIA-POR-INTEGRANTE.md`](GUIA-POR-INTEGRANTE.md) | Reparto de tareas, pasos de Git por persona, archivos que cada uno tiene que dominar, explicación de su parte, preguntas probables y plan de estudio. |
| [`GIT-PASO-A-PASO.md`](GIT-PASO-A-PASO.md) | Git y GitHub desde cero: clonar, configurar identidad, ramas, commits, push, Pull Requests, conflictos y comandos de emergencia. |

## Orden sugerido de lectura

1. `GUIA-JAVA.md`, para tener la base del lenguaje.
2. `RECORRIDO-DEL-CODIGO.md`, para entender el proyecto.
3. `GUIA-POR-INTEGRANTE.md`, para saber qué le toca a cada uno.
4. `GIT-PASO-A-PASO.md`, cuando haya que subir el aporte.

## Regla importante

Ninguna guía reemplaza leer y ejecutar el código. Antes de la entrega hay que compilar, probar los menús y poder explicar el flujo de una operación de punta a punta.
